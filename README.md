# Ledger — expense tracker

A personal expense and income tracker that runs as a standalone app on your iPhone.
All data stays on your device. Nothing is sent to any server, and this repository
contains only the app code.

## Features
- 38 built-in categories plus your own, with icons
- 34 currencies; each entry keeps the exchange rate it was saved with
- Edit, delete (with undo) or duplicate any entry
- Donut chart of spending by category, daily and monthly charts
- Monthly and per-category budgets
- Insights: savings rate, top category, changes vs last period
- CSV export and import, plus full backup and restore
- Works offline once installed

## Install on iPhone
1. Open the GitHub Pages link in **Safari**.
2. Tap **Share** (under the ••• menu on newer iOS), then **Add to Home Screen**.
3. Open Ledger from its Home Screen icon.

## Keep your data safe
Data is stored inside the Home Screen app. Removing the icon deletes it.
Use **Settings → Backup & restore → Save backup** regularly and keep the file
in Files or iCloud Drive.
